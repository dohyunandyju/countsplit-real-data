# countsplit-real-data
This R markdown file compares various methods of inference after clustering on scRNAseq data from the Zheng dataset, accessed from the DuoClustering2018 package in R (https://csoneson.github.io/DuoClustering2018/). Specifically, we are investigating the naive (double-dipping) method, data thinning (countsplit), and conditional selective inference (CADET).
